# steam-games-projects-
group project for the data science toolbox 
The topic for our Data Science Toolbox project: “Steam Hidden Gems: Why Do Great Games Go Unnoticed?”

We could use the 93,182 Steam Games dataset from Kaggle, which contains information about video games, including prices, genres, release dates, player reviews, and playtime.

The idea would be to build an interactive dashboard for a small game studio or market research team, answering two questions:

1. Which games have exceptionally high player satisfaction despite receiving relatively few reviews?

2. How do game genres and pricing relate to player satisfaction, and which market segments appear most promising?

We would clean and analyze the data using pandas, calculate player satisfaction scores, collaborate through GitHub, and build a Dash dashboard featuring a hidden gems ranking, genre comparisons, interactive charts, and game filters.

The dataset offers plenty of opportunities for interesting visualizations and business insights without requiring complex machine learning.

Since the data represents a historical snapshot, we would focus on exploring patterns rather than predicting future success.

I think this could be a fun and original way to apply data science to a real industry while keeping the project manageable!
